# NowSilence 🤫

**Filtro Inteligente de Notificaciones con IA Local para Android**

NowSilence procesa las notificaciones entrantes de forma 100% privada dentro del dispositivo, utilizando un LLM local (Google AI Edge SDK).

## Enfoques

- **Particular**: bienestar y reducción de estrés.
- **Empresarial**: productividad e integración con herramientas de trabajo.

## Arquitectura

Clean Architecture: data / domain / presentation. Kotlin + Jetpack Compose (Material 3). minSdk 26.
